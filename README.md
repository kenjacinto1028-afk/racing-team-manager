# Racing Team Manager

A browser racing team management game. Run a team, hire drivers and staff, upgrade the car, race live, and climb from Formula Academy to Formula Prime through promotion and relegation.

**Play:** https://kenjacinto1028-afk.github.io/racing-team-manager/

## Develop
```
npm install
npm run dev     # http://localhost:5173
npm test
```
Every push to `main` runs the tests, builds the game and publishes it to GitHub Pages.

See `docs/PLAN.md` for the design and `PROGRESS.md` for status.
